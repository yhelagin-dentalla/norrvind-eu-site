Windows · NorrPlan

Projects make more sense as a timeline.

NorrPlan keeps projects, participants, events, notes and decisions connected in one clear chronology — without turning everyday work into heavyweight project management.

PROJECTS / CHRONOLOGY / PARTICIPANTS / LOCAL DATA

Project memory / 01

See what happened, not just what is due.

The middle of a real project is rarely a neat task list. Decisions, calls, documents, pauses and people form a history. NorrPlan is being designed around that history.

01 / PROJECT

Project-centred

The project itself remains the organising object instead of scattering information across unrelated modules.

02 / TIME

Chronology first

Events and records form a readable sequence so the state of the project can be reconstructed quickly.

03 / PEOPLE

Participants are visible

Contacts, organisations and project roles stay attached to the work where they are actually relevant.

04 / CONTROL

Explicit responsibility

Shared work is designed around understandable roles and ownership rather than ambiguous access.

05 / DATA

Local working database

The architecture prioritises a practical local database with deliberate backup and recovery controls.

06 / CLARITY

Nothing ornamental

The interface is being built to make history, status and the active project obvious at a glance.

A project is not only a plan for the future. It is also a record of how you got here.

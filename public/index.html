Principles / 02

Software should feel understandable.

We prefer explicit actions over invisible automation, local data over mandatory cloud dependency, and durable ownership over recurring friction.

A simple test
Can you open it, understand it and get useful work done without reading a manual first?
IF YES → KEEP IT. IF NOT → SIMPLIFY IT.
Local firstYour work remains useful without a permanent connection or mandatory NORRVIND account.
Visible controlsImportant actions are explicit. We avoid hiding core behaviour behind opaque automation.
Built to lastStable workflows and straightforward ownership matter more than feature inflation.
01 / CALM

Less interface

Every screen should earn its place. Fewer decisions, fewer interruptions, clearer work.

02 / CONTROL

No black boxes

The user stays in charge. Automation should assist rather than quietly take over the workflow.

03 / OWNERSHIP

No subscription reflex

When a product can sensibly be owned instead of rented, we prefer the simpler model.

We create software the way we would want to use it ourselves.
